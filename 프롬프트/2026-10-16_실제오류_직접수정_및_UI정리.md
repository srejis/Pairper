# 직접 수정과 재검증 요청

사용자의 최신 지시로 이전 직접 수정 금지를 해제한다. 수정 제안만 넘기지 말고 실제 문제 재현 → 원인 분석 → 수정 → 동일 사례 재검증을 반복한다.

사용자용 원본 확인 버튼·오른쪽 대조 패널·확대축소와 관련 상태·이벤트를 제거한다. 원본 PDF와 추출 데이터, 그림·표·수식 표시용 이미지 및 내부 검증과 MCP 도구는 유지한다.

수동 글자 크기 설정을 제거하고 제한된 범위의 반응형 본문 크기와 공통 비율로 제목·소제목·캡션·표·수식을 표시한다. 목차와 기존 논문 렌더링을 유지한다.

이미 확인된 문단·하이픈 및 PDF 클리핑 검증 오류를 실제 논문으로 수정·재검증한다. 미발생 문제를 위한 기능·추상화·예외 처리를 추가하지 않는다.
