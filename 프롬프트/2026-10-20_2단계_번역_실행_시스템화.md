# Pairper 한국어 해석 실행 시스템화

사용자 지시(2026-10-20): “더 말안할게 내 시간 그만뺏고 시스템화 해”.

이전 작업은 에이전트가 6편의 한국어 결과를 직접 작성·교정하고 저장·보호·화면 기능을 구현한 것이었다. 원문 문맥 구성, AI 번역, 원문 대조, 문제에 따른 수정 및 재검증을 프로그램이 반복 실행하는 일반 절차를 구현하지 않은 채 전체 완료로 보고한 잘못을 정정했다.

이번에는 실제 Python 제품에 재개 가능한 작업 상태, 원문 기반 작업 분할·문맥·원본 이미지 제공, 실제 연결 AI 호출, 독립된 검토 호출, 문제별 수정·재검증, 실패/미검토 차단과 이력을 구현한다. 기존 한국어 결과·사례별 수정문구·이전 검토승인을 새 실행의 입력으로 사용하지 않는다. 현재 검증된 1단계 원문 뷰와 원본 PDF는 입력으로 사용하고 보존한다.

고정 예시6편을 새 실험으로 다시 처리해 실행흐름이 결과를 생성하고 문제를 수정한 실제 요청/응답/출처/전후/검사 이력을 보존한다. 원문/한국어 대응과 전체 표·수식·그림을 검사하고 실제 읽기 화면에서 확인한다. 실제 시스템 실행에 실패하거나 의미 검토가 남으면 미완료로 보고하며 샘플 교정을 시스템 완료로 대체하지 않는다. GitHub는 읽기 전용, commit/push하지 않는다. 기존 사용자 데이터는 별도 실험과 백업으로 보존한다.
