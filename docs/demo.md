# 실제 논문 데모 촬영 지침

[README](../README.md)

## 현재 공개 이미지

[screenshots/ui-redesign/](screenshots/ui-redesign/)의 파일은 2026-10-16 실제 앱 캡처이며, 내용은 UI 검증용 합성 PDF입니다. [당시 보고서](ui-redesign-report.md)의 기능·검증 범위와 함께 읽습니다. 실제 논문 해석·해설의 품질 증거로 사용하지 않습니다.

## 실제 논문 이미지 자리 — 아직 촬영하지 않음

1. 공개·재사용 권한을 확인한 PDF 한 편을 고릅니다. 제목·저자·원문 출처를 캡션에 남깁니다.
2. 깨끗한 테스트 라이브러리에서 PDF 추가와 미처리 상태를 촬영합니다.
3. 연결한 AI에서 업데이트를 요청하고 원문·제목·한국어의 실제 결과를 확인합니다.
4. 같은 부분의 원문/한국어 전환과 원본 대조를 촬영합니다. 수식·표가 있다면 읽을 수 있는 크기로 보입니다.
5. AI 대화창에서 논문 ID·페이지·절을 지정한 질문과 후속 질문을 촬영합니다. 현재 위치 자동 공유나 앱 내부 채팅이 있는 것처럼 편집하지 않습니다.
6. 이미지가 준비되면 README 상단에 대표 화면 한 장, 짧은 사용 순서에 영상/연속 캡처를 연결합니다.

촬영 전 터널 키·터널 ID·계정·개인 파일 경로·다른 논문 목록·비공개 원문이 노출되지 않는지 확인합니다. 실제 앱에 없는 클릭형 해설 화면을 합성하지 않습니다. 앱 버전·커밋·촬영일·논문 출처·준비된 데이터 여부를 캡션에 표시합니다. 이 작업에서는 새 제품 이미지나 데모 영상을 생성하지 않았습니다.
