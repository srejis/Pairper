# 1단계 구현 결과

## 구현한 범위

로컬 PDF 등록부터 원본 보관, 추출 데이터 조회, MCP 블록 구성/수정/재개, 원문 대응 검증, 저장된 1열 HTML 문서의 QtWebEngine 열람까지 연결했습니다. GUI는 등록 시 AI를 호출하지 않습니다. 앱과 MCP는 독립 프로세스이며 같은 SQLite WAL 저장소를 사용합니다.

원본은 SHA-256으로 중복 판별하며, 이름이 달라도 같은 바이트는 기존 항목을 반환합니다. 바이트가 달라지면 별도 원본입니다. 등록을 시작할 때 파일을 스냅샷으로 복사해 입력 변경 경쟁을 피합니다. 동시 등록과 작업 생성은 DB 고유 제약 및 쓰기 트랜잭션으로 직렬화합니다.

12종 블록, 줄 결합/하이픈 결합 이력, 인라인/블록 수식, 셀 병합 표, 그림/벡터 영역, 캡션 관계, 각주와 참고문헌을 지원합니다. KaTeX와 글꼴은 저장소에 포함되어 있습니다. HTML 이스케이프·CSP·로컬 파일 허용 목록·외부 네트워크 차단을 적용합니다. 전체 HTML은 로컬 파일로 로드합니다.

## 원본 보존 검증 수준

- 원본 PDF 해시를 조회/검증 시 대조합니다. 최초 span 문자열과 서식·좌표를 영구 보존합니다.
- 실제 출력할 refs와 블록의 source_refs를 대조합니다. 누락·중복·없는 ID·잘못된 좌표·중복 순서·표 셀 겹침·자산 연결·그림/벡터 영역 커버리지를 검사합니다.
- 장식 요소 생략에는 근거를 요구하며 페이지 여백, 페이지 번호 형식 또는 반복 여부를 검사합니다. 의미적 판단의 완전한 자동 검증은 아닙니다.
- 불확실한 수식/표는 원본 이미지를 표시합니다. 복원된 수식/표에도 원본 대조 펼치기가 있습니다. KaTeX 구문 오류는 원본 이미지로 대체합니다.
- `visual_review_pages`, `source_verified`는 작업자의 명시적 검토 진술입니다. 자동 검사는 **읽기 순서·수학적 동치·올바른 도표 경계·모든 의미의 보존을 증명하지 않습니다.** 그림에 텍스트가 없거나 추출이 잘못된 경우도 시각 대조가 필요합니다.
- 검증 결과/문서 JSON/HTML은 작업별 파일로 먼저 쓰고, DB 트랜잭션에서 현재 뷰 연결을 확정합니다. 실패하면 현재 완료 뷰 연결을 바꾸지 않습니다. 중단 시 미연결 파일이 남을 수 있지만 DB가 기준이므로 완료 뷰가 되지는 않습니다.

## 검증 결과

- pytest **16개 통과**: SHA 중복/재시작/바이트 보존, 동시 등록/작업 단일성, 작업 재개/멱등 배치, 상태 전환/새 PDF만 대상화, 누락/중복/없는 참조 거절과 복구, 원본 손상/경로 차단, 잘못된 PDF, 스캔 fallback, 스키마 거절, 이스케이프/변경 이력, 거짓 참조 차단, 실패 상태/복구, 잘못된 블록·생략 기록 제거, 영역 회전/전체 페이지 대체 거절, 벡터 그림 누락 거절, MCP 입출력/페이지·영역 이미지/뷰 확정, 실제 stdio 자식 프로세스 연결.
- Ruff 검사 통과. 소스 배포본과 wheel 빌드를 확인했고 wheel에 로컬 KaTeX JS·CSS·글꼴이 포함되는지 검사했습니다.
- QtWebEngine 통합 검증: 합성 테스트 문서 14개 블록에서 12종 블록 전체, 정상 KaTeX 2개, 잘못된 수식 1개의 원본 fallback, 병합 셀, 깨진 이미지 0개를 확인했습니다. 앱을 켠 상태에서 별도 Library 인스턴스로 완료한 뷰가 자동 갱신되었습니다.
- Windows 네이티브 캡처에서 실제 1열 문서와 한글 UI를 확인했습니다. offscreen 검증의 글꼴/GPU 문제가 있어 Windows 플랫폼과 명시적 시스템 글꼴을 사용했습니다. 이 환경에서 Chromium GPU 초기화 로그가 남아 테스트에는 `--disable-gpu`를 사용했습니다. 일반 앱에는 강제하지 않으며 실행 스크립트 옵션으로 제공합니다.
- 공식 SDK 2.3.0의 실제 `MCPServer`, `Client`, `StdioServerParameters`, `ImageContent` API로 실행했습니다. PNG 바이트가 MCP 클라이언트까지 도달하는 것을 확인했습니다.

## 아직 검증하지 못한 범위

**지정된 arXiv:2412.15750v1 PDF가 작업 폴더에 제공되지 않았습니다.** 합성 테스트 PDF는 단위/렌더러 검증에만 사용했으며 해당 논문을 대체하지 않았습니다. 13페이지 논문의 2단 문단 순서, 5페이지 도식, 7페이지 Table 1, 13페이지 회전 표, 참고문헌/부록 보존은 아직 검증하지 않았습니다.

**GPT가 실제 논문 이미지와 텍스트를 함께 보고 재구성한 결과는 아직 없습니다.** 로컬 MCP 클라이언트에 PNG가 전달된 것까지만 확인했으며, 실제 모델의 시각 사용을 증명한 것으로 보고하지 않습니다.

**ChatGPT 연결은 미검증입니다.** 터널 ID/조직·워크스페이스 권한/런타임 키/사용자 지정 MCP 연결이 제공되지 않았습니다. 실행 문서를 작성했지만 터널을 생성하거나 ChatGPT 계정을 변경하지 않았습니다.

## 기술적 한계와 다음 검증

OCR은 포함하지 않습니다. 스캔 페이지는 원본 이미지로 보존하고 텍스트 추출 불가를 명시합니다. 추출 단위는 PyMuPDF span이므로 하나의 span 중간에 수식을 분리하려면 원본 영역 fallback을 활용해야 합니다. 아주 큰 논문의 span/문서 JSON은 메모리에 적재하므로 향후 페이지별/블록별 DB 분할을 검토할 수 있습니다. PDF 손상·자산 손실의 자동 복원이나 작업 이력 정리 UI는 없습니다.

다음으로 실제 테스트 PDF를 등록하고 연결된 GPT가 전 페이지 이미지를 확인하며 문단·수식·표를 구성하도록 검증해야 합니다. 이후 원본과 읽기 순서/수식/숫자를 수동 대조하고, 실제 ChatGPT 터널에서 “Pairper 논문 업데이트해 줘” 명령을 끝까지 확인해야 합니다. 따라서 A–C의 로컬 구현 및 검증은 수행했지만 D–E의 실제 논문/ChatGPT 완료 기준까지 충족했다고 주장하지 않습니다.
